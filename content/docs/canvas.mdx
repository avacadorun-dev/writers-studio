A Canvas is a visual workspace inside a project. Combine thoughts, manuscript
documents, references, drawings and relationships. Use separate boards for a
story timeline, dialogue graph or game loop. Explore the [demo](/docs/example-project)
for a populated example.

## Tools and capture

The vertical toolbar groups selection/hand, add, drawing, layout, views/analysis
and selection actions. Hover or focus an icon for its label. Escape, another click
on the group or a canvas click dismisses an open group.

Double-click empty space to add a Markdown note; double-click text to edit it and
use Cmd/Ctrl+Enter to finish. Paste text/images/URLs or drop a supported file.
Document cards show title/status/excerpt and open Studio on double-click. Add one
through the toolbar or drag it from the tree. Promote an idea to a document with
an atomic operation that cannot leave a half-created result.

Supported resources include images, safe HTTP(S) previews, PDF up to 25 MiB,
MP3/M4A/OGG/WAV and MP4/WebM, and links to another board without recursive live embeds.

## Drawing and shortcuts

Pen preserves compatible stylus pressure; highlighter produces translucent strokes.
A complete gesture is one history operation. Shapes support resize, rotation,
color, copying and connections. Eraser removes shapes or splits freehand strokes.
On supported tablets, stylus draws while two fingers pan/zoom and palm contact is
ignored during a pen gesture.

Use V for selection, H for hand, N for note, C for connection, P for pen, M for
highlighter and E for eraser. R/O/D/L/A select shapes. Hold Space for temporary pan.
Ordinary Cmd/Ctrl+C, X, V, D, Z, Shift+Z, A and Delete/Backspace remain available.

## Connections and layout

Cards/shapes have four connection handles. Reconnect, color, type and double-click
to label edges. Lasso selects multiple objects. Groups move enclosed cards but
removing a group leaves those cards. Frames also define presentation order.

Guides show aligned edges/centers and equal spacing; Alt temporarily disables
snapping. Multi-selection supports alignment, distribution, tidy grid and automatic
layout preview. Layout runs away from the UI thread and its application has one Undo.
Copies retain only connections between copied objects.

## Views and typed design

View the same board as free Canvas, mind map, timeline, swimlanes, dependency graph
or filtered projection. These views do not rewrite original coordinates.

The project catalog defines card types, fields, colors, icons and relationships.
Built-ins include Idea, Question, Source, Character, Location, Beat/Event, Conflict,
Theme, Mechanic, Quest, Dialogue, State, Level and Resource. Fields include text,
Markdown, numbers, flags, choices, dates, duration and document/media/board links.
Relationships such as causes, depends_on, blocks, reveals, transitions_to,
consumes, produces and rewards support analysis; custom types coexist with them.

## Analysis, play-through and presentation

Diagnostics identify disconnected components, orphan nodes, cycles, roots/leaves,
critical paths, unreachable quests/dialogue, states without exits and resources
without producers/consumers. Warnings do not prevent saving. Select one to focus
its related objects.

Manual play-through traces dialogue, quest or state choices. Presentation follows
frames; object search and the minimap aid navigation. A local focus timer can
bound a brainstorming session.

## Assistant review

Select cards before opening the assistant. Its target includes board ID/revision,
selection and viewport. It can propose analysis, grouping, connections, types,
layout or document promotion. Ghost review shows proposed additions/deletions/moves.
Only Apply changes the canonical board; stale proposals require refresh.

## Saving and portability

Local recovery precedes server saves. Idle autosave and a maximum 15-second attempt
interval retain continuous work. Offline/reload recovers unsynced snapshots; stale
parallel writes create a separate conflict board.

Export a board/selection/frame to PNG/SVG/PDF or exchange the editable `.canvas`
core. Full `.wstudio` archives carry documents, every board revision, type catalog
and media. See [export and transfer](/docs/export).

<Callout type="info" title="Desktop, tablet and phone">
  Desktop provides the full tools. Screens from 768 px support stylus drawing and
  basic layout. Phones use viewing, pan/zoom and resource navigation.
</Callout>
