Reader exports share a manuscript with an editor, reader or printer. A native
`.wstudio` archive preserves your working project so editing can continue elsewhere.

## Reader formats

Open project export, choose and order documents, exclude private working notes,
then review metadata, formatting and preview before generating the file.

<figure>
  <img src="/docs/images/export.png" alt="Reader export settings for a synthetic project" />
  <figcaption>Check the selected materials, formatting and page preview.</figcaption>
</figure>

- **TXT:** plain text.
- **Markdown:** portable headings, lists and links.
- **DOCX:** further editorial work.
- **EPUB:** an ebook with navigation and cover.
- **PDF:** fixed pages for reading or printing.

Open the downloaded file and inspect chapter boundaries, tables, images, breaks
and contents. Export does not change the source manuscript; adjust the profile
and regenerate instead of editing source text to fix one output format.

## Complete native archives

Current `.wstudio` v8 transfers the document tree and revisions, every Canvas
revision, typed card/relation catalog, images, PDF, supported audio/video, dictionary,
project settings and internal document/media/board references. The importer also
accepts supported older v1–v7 archives.

Import creates an independent copy with new IDs and remapped internal references.
It never replaces an existing project. Account credentials and provider keys are
not part of a project archive.

<Callout type="warning" title="An archive can contain unpublished work">
  Store backups separately from your working device. Review them before sharing:
  drafts, recordings, visual references and project metadata may be included.
</Callout>

## Test a backup

1. Export the project as `.wstudio` and import an independent copy.
2. Open several documents and every board.
3. Check images, PDF, audio/video and nested-board navigation.
4. Export the copy and import it again.

A second round-trip can reveal problems a successful download cannot. Practice
with the [synthetic demo project](/docs/example-project).

## Individual boards

Canvas can export a board, selection or frame to PNG, SVG or PDF. SVG retains
vector strokes/connections; PDF can follow frame order. `.canvas` exchanges the
editable JSON Canvas core and compatible extensions. Use `.wstudio` for a full
backup containing documents and binary resources.
