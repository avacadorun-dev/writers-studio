A project is the workspace for a book, article, script, or research task. Separate projects keep their dictionaries, assistant conversations, structure, and exports independent.

## Create a project

On the **Projects** page, choose **New project**, enter a clear name, and select a suitable type. The type provides a useful starting structure. You can rename, add, or move folders and documents later.

After creation, the project card appears. Open it, create a document, and give it a name that describes its content: “Meeting at the harbor” is usually more useful than “New version 2.”

## Folders, documents, and order

A folder groups related materials; a document holds the text. Drag items in the project tree to change their order or nesting. After a move, check that the document appears in the right folder. Its text stays the same.

To remove material, move it to the trash. You can restore it until the trash is emptied. Permanent deletion requires confirmation; afterward, the interface cannot restore the material.

<Callout type="warning" title="Before emptying the trash">
  If you may need the text later, export the project first, or restore the document and save a separate copy.
</Callout>

## Import

Markdown is useful for text with headings, lists, and simple formatting. A `.wstudio` file transfers an entire project, including its structure and the data contained in the backup.

To try importing before using your own archive, download the [Echo Frontier demo](/docs/example-project). It already includes documents, several Canvas boards, images, a PDF, audio, and video. The sample project’s own content is in Russian.

Before importing, check the filename and selected project. Afterward, open several documents, review their headings, and check the structure against the original. If the import created an extra project, compare the materials first, then transfer anything missing or remove the duplicate through the trash.

## Troubleshooting

- A document is in the wrong folder: drag it back. Its text is retained.
- Imported Markdown looks different: check complex tables, embedded HTML, and images, then adjust the affected passages.
- A project will not open: refresh the page and check your connection. If you edited offline, visit the [recovery center](/docs/recovery).
