---
title: Short glossary
description: Plain explanations of terms used in the Studio and its settings.
---

You can read the main guides without this glossary. Use it when you encounter an unfamiliar term in the interface or a support message.

**Version** — a saved state of a document that you can return to later.

**Change set** — a group of related edits that the assistant proposes for review together.

**Diff** — a comparison showing removed and added passages alongside unchanged text.

**Source reference** — a pointer to the document or passage from which a fact was taken.

**AI provider** — a service that handles assistant requests or recognizes speech. The server owner configures the system provider; you configure a personal provider.

**API key** — a secret string granting access to an external service. Treat it like a password.

**MCP** — a way to connect an external tool to the assistant with explicitly defined capabilities. Connecting a tool should not require publishing its key in text or chat.

**Markdown** — a plain text format that uses readable symbols for headings, lists, and links.

**Mermaid** — a way to describe diagrams as text, which the Studio renders visually.

**Transcript** — text produced from an audio recording. It becomes manuscript text when you transfer a selected passage.
