## Как открыть

1. Скачайте файл по кнопке выше.
2. Откройте страницу **«Проекты»** и нажмите **«Проект Writers Studio»** в блоке импорта.
3. Выберите `echo-frontier-canvas-demo.wstudio` и дождитесь сообщения об успешном импорте.
4. Откройте проект **«Эхо Предела — игровой концепт»**.
5. В разделе **«Доски»** начните с **«Vertical Slice — карта дизайна»**.

## Что находится внутри

**Vertical Slice — карта дизайна** показывает связанный core loop, игровые системы, moodboard, риски плейтеста и фрейм «Попробовать всё». Здесь есть документы с разными статусами, Markdown-идеи, spatial group, изображения, фигуры, свободные штрихи, типизированные связи, внешняя ссылка и переходы на другие доски.

**Референсы острова** — отдельная moodboard-доска. Она показывает, что один проект может держать несколько самостоятельных Canvas, а карточка вложенной доски выполняет понятный переход без рекурсивного live-embed.

**Canvas 0.5/0.6 — лаборатория** собрана как каталог возможностей:

- pen, highlighter, rectangle, ellipse, diamond, line, arrow, rotation, fill и locked element;
- frames и порядок презентации, группы, подписи и неизвестное extension-поле для проверки lossless transfer;
- изображения, PDF с тестовым планом, звуковой сигнал MP3 и короткий MP4 field log;
- Idea, Question, Source, Character, Location, Beat/Event, Conflict, Theme, Mechanic, Quest, Dialogue, State, Level, Resource и пользовательский тип;
- short text, Markdown, number, checkbox, single/multi-select, date, duration и ссылки на document/media/canvas;
- все встроенные relation types и пользовательская направленная связь;
- quest, dialogue, state и economy-фрагменты для диагностики и ручного play-through;
- promoted document reference, вложенный Canvas и карточка о review Ассистента.

В дереве документов есть готовый материал **«Как устроен Canvas-демо проект»**. Его удобно открыть рядом с доской как короткую экскурсию по примеру.

## Что попробовать за десять минут

1. Наведите курсор на вертикальную панель, раскройте группы и посмотрите подсказки инструментов.
2. Добавьте заметку двойным нажатием по пустому месту, соедините её с документом и отмените действие.
3. Нарисуйте линию пером, добавьте ромб и поверните его.
4. Выделите несколько карточек, попробуйте направляющие, выравнивание, tidy grid и preview авто-раскладки.
5. Переключите Timeline, Swimlanes или Dependency graph и вернитесь в свободный Canvas.
6. Запустите диагностику, нажмите предупреждение и пройдите один из графов через Play-through.
7. Откройте presentation mode, PDF, аудио, видео и вложенную доску.
8. Выделите идею и откройте Ассистента, чтобы увидеть Canvas как отдельный target с review до Apply.

## Проверка переноса

Экспортируйте импортированный пример в `.wstudio`, импортируйте полученный файл ещё раз и сравните состав. В корректном цикле сохраняются три доски со всеми revisions, документы, каталог типов, изображение, PDF, аудио, видео и все внутренние ссылки с новыми ID.

Этот опубликованный файл проходит тот же двойной export → import → export → import, который рекомендуется для собственной резервной копии. Подробности формата — в разделе [«Экспорт и перенос»](/docs/export), полный справочник инструментов — в [«Canvas-досках»](/docs/canvas).
