Echo Frontier is a fictional survival-adventure concept about an island revealed
by sound pulses. Its connected documents, risks and systems form a realistic
vertical slice. The project's sample text retains its original Russian language;
this guide explains how to explore it.

This published archive is a synthetic example. Import creates your own independent
copy without changing the source example or other projects.

## Open it

Download the archive, open Projects, choose the native Writers Studio project
import action and select `echo-frontier-canvas-demo.wstudio`. After import, open
the game-concept project and start with its Vertical Slice design-map board.

## Contents

- **Vertical Slice:** core loop, systems, moodboard, playtest risks, documents with
  different statuses, Markdown ideas, groups, drawings, types and linked boards.
- **Island references:** an independent moodboard, demonstrating project board
  navigation without recursive live embeds.
- **Canvas laboratory:** pen/highlighter, shapes, rotation/fill/locking, frames and
  presentation order, groups, labels and an unknown extension field for transfer
  checks; images, a PDF test plan, synthetic sound and a short video.

The laboratory includes built-in/custom card and relationship types, all field
kinds, quest/dialogue/state/economy graph fragments, promoted documents, nested
boards and assistant review context. A document in the tree provides an in-project tour.

## Try a ten-minute session

1. Explore toolbar groups and accessible tooltips.
2. Add a note, connect it to a document and undo.
3. Draw a stroke, add/rotate a shape and inspect guides/alignment/layout preview.
4. Switch timeline/swimlane/dependency views, then return to free Canvas.
5. Run diagnostics, follow a warning and try manual play-through.
6. Open presentation, PDF, audio, video and a nested board.
7. Select an idea and open the assistant to inspect its separate Canvas target.

## Check portability

Export the imported example, import that copy, then export/import once more when
testing backups. Compare all three boards and revisions, documents, type catalog,
images, PDF, audio/video and remapped internal references. A successful download
alone is not a backup-restoration test. See [export](/docs/export) and [Canvas](/docs/canvas).
