If the Studio behaves unexpectedly, save what you can before refreshing the page or changing settings. The steps below cover common situations.

## The microphone does not work

Check that the Studio uses a secure HTTPS address: browsers usually restrict microphone access on ordinary HTTP websites. Check site permissions beside the address bar, select the correct device, and close any application that may be using the microphone. Speak a test phrase and watch the level meter.

If permission was denied, change it in the site settings and reload the page. Complete a short test successfully before beginning a long recording.

## Text is not saving

Keep the tab open. Check your connection and the status in the top bar, then copy important new text to a temporary file. When the connection returns, wait for save confirmation. If you already closed the page, open the [recovery center](/docs/recovery).

## The assistant does not respond

Check that an AI provider is selected and that its connection test succeeds. Reduce an oversized context and retry in the same conversation. Allow time for a response before sending another request, since delayed replies can create duplicate proposals.

## Privacy and deletion

Projects contain your text, audio, and settings. Keep backups private and hide keys in screenshots. Before deleting a project or account, export the materials you need and open the archive to check it.

Moving an item to the trash is usually reversible until the trash is emptied. Permanent deletion and account deletion may be irreversible. Read the confirmation carefully and check the selected item.

## Quick answers

**Does the assistant edit text on its own?** It first presents a proposal for you to apply or reject.

**Can I recover an older version?** Use Undo for a recent edit and version history for an earlier state.

**Where can I find an interrupted recording?** Open the recovery center on the same device and in the same browser.

**What should a bug report include?** Describe the steps, expected and actual results, time of the error, and browser version. A screenshot helps when it excludes your manuscript, email, keys, and other personal data.
