As a manuscript grows, consistency across the whole becomes more important. The Studio brings together margin notes, a dictionary, version history, and project search.

## Annotations and dictionary

A margin note is anchored to a passage and stays outside the manuscript text. Use it for a question, an editorial task, or a factual reminder. Resolve it when the issue is settled. Before deleting it, make sure any useful thought is in the text or outline.

Add names, places, and invented terms to the dictionary with the correct spelling and a short explanation. This helps you, dictation, and the assistant use consistent terms. After changing the dictionary, test the rule on one passage before changing the entire project.

## Version history

Versions are saved document states. Open history, use timestamps and descriptions to choose a version, and compare it with the current text. Restoration creates a new revision and retains the intervening history. Read the beginning and end of the affected section afterward.

## Search and bulk replacement

Project search finds matches across available documents. It is useful for renaming a character or checking repetition. Refine your query before replacing: consider case, word endings, and matches contained in other words.

Review the matches first. Exclude quotations, historical notes, and passages that need the old spelling. Then replace and check results in several documents. If the result is wrong, undo the operation or restore earlier versions of the affected documents.
