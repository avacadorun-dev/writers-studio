The editor supports sustained writing with formatting, search, and manuscript information close at hand.

## Autosave and checking the result

Type as usual. After a change, the indicator in the top bar briefly shows that saving is in progress, then confirms completion. Wait for that confirmation before closing the tab after a large insertion or rearrangement.

If the connection drops, keep the page open. Copy particularly important new text to a temporary file, wait for the connection to return, and check the status again. Unsaved local data may be available in the [recovery center](/docs/recovery).

## Formatting and meaningful blocks

Select a passage and apply a heading, list, quotation, link, bold, or italics. Tables help with comparisons, code blocks preserve technical text, and images can provide a useful diagram or reference.

Mermaid turns a textual description of relationships into a diagram. A callout highlights a warning, important thought, or tip. After inserting a complex block, click beside it, continue with a normal paragraph, and check the preview to make sure adjacent text stays outside the block.

## Search, focus, and statistics

Search within the document to find a name or recurring phrase. Project search covers multiple documents and is described in [Text control](/docs/text-control).

Focus mode hides extra panels while you continue editing the same manuscript. Leave it with the same toggle or `Escape`, and check that the usual panels return.

Statistics show the amount of text and help you track your pace. Treat them as a guide: a complete short scene is more useful than a word count alone.

## Undo an edit

Use the editor’s Undo action for a recent manual edit. For an earlier saved state or work continued on another device, open version history, compare the dates, and restore the chosen version as a new revision. The current version remains part of the history.
