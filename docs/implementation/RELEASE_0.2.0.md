# Historical release 0.2.0

This public record preserves the release's intent, not private deployment logs,
server addresses, filesystem paths or a current verification claim.

The release consolidated dictation capture/review, author-controlled manuscript
transfer, recovery and assistant workflow improvements. Data and revision
preservation remained the upgrade boundary. Use additive migrations and the
backup-first server update script; never delete application volumes to upgrade.

For reproducible checks, use the [verification guide](VERIFICATION_REPORT.md).
The architecture/specifications describe the frozen edition after later releases.
